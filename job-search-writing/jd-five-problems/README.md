# JD Five Problems

## What it does

Diagnoses the 3–5 underlying business problems a role actually exists to solve, given a job description — rather than summarizing its listed responsibilities. For each problem it infers the likely current state, the constraint that's kept it unsolved, and the downstream impact of leaving it unsolved.

## Why it exists

Job descriptions describe duties, not the business failure that triggered the req. Understanding the real problem behind a posting is what makes it possible to write a genuinely targeted application instead of a generic one that just echoes the JD's own language back.

## When I use it

Early, on any job description I'm seriously considering — before writing a resume or cover letter for it — to figure out what the company is actually hiring to fix.
