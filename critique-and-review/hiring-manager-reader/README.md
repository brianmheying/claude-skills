# Hiring Manager Reader

## What it does

Blind-reads an artifact as a senior hiring manager evaluating the author as an internal operator — testing hiring signal, operating altitude, judgment, and execution credibility, without editing the artifact.

## Why it exists

Work samples and career artifacts (case studies, writing samples, project write-ups) get judged by a very specific lens when a hiring manager reads them: does this person operate at the level the role needs? That lens is different from a peer's or a client's, and this skill applies it directly.

## When I use it

When evaluating a work sample, case study, or artifact meant to demonstrate hiring signal for a role — to see whether it reads as credible internal-operator evidence before it's used that way.
